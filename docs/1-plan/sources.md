# How things stand today

*Mark's notes, written before the planning conversation. Drafted by Claude at the owner's request, for this teaching demo.*

## The chat tools

- Our team uses four different chat tools, and nobody chose them on purpose. Each one arrived because someone liked it.

- Claude lives in one browser tab and GPT in another. One person tries an open model on NVIDIA's site. Someone else uses a plug-in inside their editor.

- A conversation started in one tool cannot move to another. When we want a second opinion, we copy the question across by hand and lose what came before.

- Nobody can find last week's useful answer, because it sits in someone else's account.

## The keys

- We hold four sets of keys, and they are not kept in one place.

- Some are in personal notes, some are in a shared document, and one was once pasted into a chat by mistake and had to be replaced.

- When someone leaves, nobody is sure which keys they had, so we replace all of them.

## What it costs us

- New starters ask which tool to use and get a different answer from each person.

- We pay for tools that overlap, without knowing who uses what.

- Choosing a model is a habit, not a decision, so we never compare answers side by side.

## What I keep coming back to

- I want one chat window where anyone on the team can pick any of these models, with the keys kept safely in one place.
